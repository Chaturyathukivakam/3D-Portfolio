## 🌐 One-Click Deployment to Vercel

This portfolio is engineered with zero build dependencies, meaning you can deploy it directly:

1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of 3D portfolio"
   git branch -M main
   git remote add origin https://github.com/Chaturyathukivakam/<repo-name>.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Leave all build and output settings at default (**Other / Static site**).
5. Click **Deploy**! Your site will be live within seconds at your own custom `.vercel.app` URL.
