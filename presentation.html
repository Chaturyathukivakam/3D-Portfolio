Technology Stack & Implementation

Alliance University

Technology Stack & Justification

• Python 3.10+: Core language for numerical speed and data reliability.

• Streamlit: Reactive web engine without frontend/backend overhead.

• Pandas: High-speed tabular aggregation, cleansing, and multi-criteria slicing.

• Plotly: Interactive vector charts with tooltip inspection and zoom.

• Git & GitHub: Production repository and continuous deployment pipeline.

• Streamlit Cloud: Serverless cloud hosting for instant public access.

Architecture Pipeline

CSV/Form Ingestion ➔ Pandas Engine ➔ Plotly Graphics ➔ Streamlit UI ➔ Public Cloud

Technical Challenge Solved

Reactivity without Data Loss: Streamlit scripts rerun upon any widget change. Solved state synchronization by architecting an encapsulated st.session_state data cache that preserves manual inputs while updating all charts in real-time.
